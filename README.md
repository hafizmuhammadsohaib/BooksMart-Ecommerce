# BooksMart

**BooksMart** is a complete e-commerce web application built using **ASP.NET Core (.NET 8)**.  
This project demonstrates real-world implementation of MVC, Razor Pages, Identity, EF Core, payments, and deployment workflows.

---

## **🚀 Features & Learning Outcomes**

**Project Structure & Frameworks**
- **Learn structure of ASP.NET MVC Core (.NET 8) Project**
- **Learn structure of ASP.NET Core (.NET 8) Razor Project**

**Identity & Authentication**
- **Integrate ASP.NET Core Identity Framework**
- **Extend Identity User with custom fields**
- **Use Razor Class Library for Identity UI**
- **Authentication and Authorization**
- **Role Management in ASP.NET Core Identity**
- **Email Notifications for user actions**

**Data & Database**
- **Entity Framework Core integration**
- **Code-first migrations**
- **Repository Pattern for data access**
- **Seed database migrations automatically**

**UI & Application Components**
- **Bootstrap v5 responsive layout**
- **Sessions in ASP.NET Core (.NET 8)**
- **Custom Tag Helpers**
- **View Components and Partial Views**
- **TempData for UI feedback**

**Payments & Integrations**
- **Stripe Payment Integration**

**Deployment**
- **Publish and deploy on Microsoft Azure**

---

## **🛠️ Technologies Used**
- **ASP.NET Core 8 (MVC + Razor Pages)**
- **Entity Framework Core**
- **ASP.NET Core Identity**
- **Stripe Payments**
- **Bootstrap 5**
- **Microsoft Azure**
- **Repository Pattern**

---

## **📦 Project Goals**
- Build a production-ready e-commerce platform for books
- Learn modern ASP.NET Core 8 features through real implementation
- Understand authentication, roles, payments, database patterns, and deployment practices

---

## **🚀 Deployment**
Fully deployable to **Microsoft Azure App Service** with database migrations and Identity setup pre-configured.
